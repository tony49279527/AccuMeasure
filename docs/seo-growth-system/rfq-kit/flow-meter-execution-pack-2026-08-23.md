## Publication copy

### Title

Flow Meter Sourcing Checklist for Water Treatment and Industrial Piping

### Description

A practical checklist for collecting fluid, pipe, installation, signal, and documentation requirements before comparing electromagnetic, clamp-on ultrasonic, or thermal mass flow meter options.

### Buyer value

Use this checklist before requesting quotations so suppliers receive the process and installation information needed for a meaningful technical review.

### Call to action

Complete the checklist, attach available pipe and process information, and request an engineering review when the application needs model confirmation.

### Safety footer

This checklist supports early project definition. Final model selection, operating limits, certificate scope, calibration requirements, and commercial terms must be confirmed against current controlled documents and the quotation.
