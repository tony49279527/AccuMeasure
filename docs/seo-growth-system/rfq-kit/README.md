# AccuMeasure Industrial Measurement RFQ Kit

This folder contains buyer-facing draft templates for level, flow, and pressure instrument sourcing.

## Release rules

- These are local drafts. Do not publish or distribute them until Owner review is complete.
- Keep the forms neutral. The templates help buyers compare requirements; they do not certify AccuMeasure or any other supplier.
- Add only approved product facts, certificate scope, customer references, or performance data.
- A published version should link to the relevant AccuMeasure application guide and RFQ/contact path.
- Track each distribution source, referral visit, download, completed RFQ, qualified inquiry, and response time.

## Draft assets

- `level-sensor-rfq-template.md`
- `flow-meter-sourcing-checklist.md`
- `oem-pressure-instrument-qualification-sheet.md`
- `instrument-supplier-evaluation-sheet.md`

## Suggested pilot

Use one asset with one approved industrial directory, association, distributor, or system integrator. Do not distribute all four at once. A 60-90 day pilot should measure qualified buyer activity, not backlink count.
