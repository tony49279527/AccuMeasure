# AccuMeasure Industrial Measurement RFQ Kit

## 目的

把 AccuMeasure 的专业知识做成工业采购方、系统集成商、分销商和协会愿意转发的实用资源。传播目标不是索要 backlink，而是让合作方有理由把资源放进自己的采购指南、培训页、活动页或客户邮件中。

**当前阶段：** 本地策划与证据审查  
**外部状态：** 未联系、未投稿、未注册、未付费  
**目标域名：** `https://www.accumeasuretech.com`

## 资产包结构

### 1. Level Sensor RFQ Specification Template

采购方填写：

- 介质名称、液体或固体、浓度和是否有泡沫；
- 罐体/料仓高度、测量范围、喷嘴尺寸和安装位置；
- 温度、压力、粉尘、蒸汽、搅拌器或内部障碍物；
- 输出信号、电源、通信协议、显示和防护等级；
- 是否涉及危险区域，要求的认证名称、区域和保护型式；
- 数量、样品需求、目标交期、目的地和所需文件。

推荐配套页面：

- `/applications/radar-level-sensor-for-oil-tank`
- `/applications/radar-vs-ultrasonic-level-sensor`
- `/products/level`
- `/contact`

### 2. Flow Meter Sourcing Checklist

采购方填写：

- 流体名称、导电性或气体介质；
- 管径、管材、内衬、电极材料、法兰标准和压力等级；
- 最小/正常/最大流量、温度和压力；
- 直管段、接地、安装方向和是否可以停机切管；
- 输出信号、通信、显示、校准和检验文件；
- 现场改造、临时审计还是永久安装。

推荐配套页面：

- `/applications/electromagnetic-flow-meter-for-water-treatment`
- `/compare/electromagnetic-vs-ultrasonic-flow-meter`
- `/products/flow`
- `/contact`

### 3. OEM Pressure Instrument Qualification Sheet

OEM 或系统集成商填写：

- 正常压力、过载/冲击压力和压力范围；
- 精度等级、输出信号、电源、显示和通信；
- 过程连接、湿接触材料、密封、外壳和环境温度；
- 振动、冲击、安装空间和线缆要求；
- 标签、包装、固件、说明书、校准证书和批次追溯；
- 样品数量、定制数量、预计年量和变更控制要求；
- 是否需要 NDA、图纸审查或私牌文件。

推荐配套页面：

- `/applications/pressure-transmitter-for-oem-equipment`
- `/customization`
- `/products/pressure`
- `/contact`

### 4. Instrument Supplier Evaluation Sheet

供采购方比较供应商：

- 公司注册主体和制造范围；
- 产品型号、数据表和版本日期；
- 证书原件、签发机构、适用型号和有效期；
- 校准、检验、序列号追溯和出货文件；
- 样品测试、验收标准、保修和售后负责人；
- MOQ、交期、包装、贸易条款和询盘响应 SLA；
- OEM 变更、投诉和不合格品处理流程。

该表应教育采购方核验供应商，不能预先把 AccuMeasure 标成“已通过所有项目”。

## 证据边界

### 可先使用的内容

- 液位、流量、压力和 OEM 产品类别；
- 工况字段和选型逻辑；
- 官网已有的产品、应用、对比和联系页面；
- “最终型号、认证范围、文件版本需在报价前确认”这一采购流程；
- RFQ 中应提供的数据字段和买方需要索取的文件清单。

### 必须 Owner 审批后才能使用

- ISO 9001、CE、ATEX、RoHS 的证书编号、签发机构、有效期和型号范围；
- IECEx、FCC Part 15 等具体合规声明；
- 72h aging、校准证书、人员、工厂面积、产能和出口国家数字；
- 客户名称、订单数量、重复订单、节省比例、交期和零故障结果；
- “每台产品”“保证”“已认证”“可用于某危险区域”等绝对性表述。

### 明确不使用

- 未授权客户 Logo 或案例；
- 未经核验的证书扫描件；
- 购买链接、交换链接或“保证 dofollow”宣传；
- 抽奖式虚假活动、虚构评测、伪造买家评论；
- 用合作方网站发布未经批准的 AccuMeasure 产品声明。

## 合作传播设计

### 合作方类型

1. 工业仪表目录：把 RFQ 模板作为采购资源，而不是付费公司简介。
2. 自动化协会：将 Flow/Level 选型清单作为培训或会员资源。
3. 系统集成商：联合制作客户工况收集表，减少项目澄清往返。
4. 分销商：使用白标或联合品牌版本收集客户规格，再由双方承接询盘。
5. 工业媒体：提供独立的采购指南或专家访谈，不要求预设关键词锚文本。
6. 展会主办方：将“展前 RFQ 准备表”作为参会者下载资料。

### 合作流程

1. 先给合作方一个不含未经批准声明的样稿和预览 URL；
2. 合作方决定是否把它放入自己的资源页、培训页、活动页或邮件；
3. AccuMeasure 页面承接下载、工况收集或 RFQ；
4. 合作双方只记录真实来源、下载和合格询盘；
5. 不要求固定锚文本、不要求互链、不购买 placement；
6. 每个合作方单独记录页面 URL、发布时间、链接属性、引荐访问和线索归属。

## 评价指标

### 主要指标

- 合作方是否主动把资源放进真实买家页面；
- 引荐访问中的产品页访问和 RFQ 启动；
- 下载后合格询盘数量；
- 采购方填写完整工况的比例；
- 首次响应时间和销售归属是否明确；
- 品牌在相关工业问题中的提及、引用和 AI 可见性变化。

### 不作为主要指标

- 单纯 backlink 数量；
- DA/DR 或第三方 authority 分数；
- 没有访问和询盘的目录收录数；
- 付费 placement 的 dofollow 数量。

## 下一步执行顺序

1. Owner 审批 RFQ Kit 的产品范围和证据边界；
2. 在本地把四个模板整理为英文可交付版本；
3. 选择一个低成本目标先做试点，优先 MCAA、Instrumentation Directory 或 DirectIndustry 其中之一；
4. 准备一个合作方预览页和一个 AccuMeasure RFQ 承接页；
5. 获得明确授权后再进行一对一人工联系；
6. 试点运行 60–90 天，只保留产生相关采购访问或合格询盘的渠道。

## 本轮结论

当前不应继续增加目录数量。最有价值的工作是把已有的应用中心、对比页和 RFQ 表单组合成一个第三方愿意传播的采购工具，并在证据批准后逐个验证合作方。这个资产完成后，authority 建设才从“申请列表”进入“可被引用、可产生买家行为的合作机制”。
