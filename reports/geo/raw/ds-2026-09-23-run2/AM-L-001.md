# Radar Level Transmitter: Export Packaging & Shipping Requirements

Radar level transmitters are precision **electronic + microwave** instruments. They combine sensitive RF electronics, a process flange/antenna, and often a display module. Proper export packaging must address **shock, vibration, moisture, static, and customs compliance**.

---

## 1. Product Classification & Shipping Considerations

| Item | Typical Detail |
|---|---|
| HS Code | 9026.10 (level/flow measuring instruments) — confirm with your broker |
| Weight | 2–15 kg depending on flange/antenna size |
| Sensitivity | RF module, crystal oscillator, LCD, ESD-sensitive PCB |
| Hazardous | Normally non-hazardous (no battery unless optional). Lithium battery versions require UN 38.3 |
| Environment | Fragile electronic precision instrument (ISTA 2A/3A level) |

---

## 2. Packaging Levels (3-Layer Protection)

### Layer 1 — Product Protection
- **Antenna protection**: Horn antennas need a rigid foam cap or PVC end-cap to prevent dents and foreign objects.
- **Flange protection**: Plastic or plywood flange cover; protect sealing faces (Ra 3.2) with soft gasket or film.
- **Process seal**: Keep diaphragm/horn protected from dust and moisture with desiccant bag + PE bag.
- **Cable entries**: Plug all M20/NPT entries with transport plugs.
- **ESD**: Wrap electronics housing with anti-static PE bag or ESD foam.
- **Desiccant**: 2–5 g silica gel per unit; use VCI (vapor corrosion inhibitor) film for sea transport.
- **Display/programming module**: Remove or secure separately if detachable.

### Layer 2 — Inner Carton
- **Molded EPE (Expanded Polyethylene) or EVA foam** cradles — preferred over bubble wrap for precision instruments.
- **Drop test**: ISTA 2A – 10-point drop from 76 cm (or per contract).
- **Carton**: 5-layer corrugated (K=K) or 7-layer for heavy flanged units.
- **Vibration**: Foam must prevent movement >2 mm inside the carton.

### Layer 3 — Export Outer Packaging
- **Export plywood case** (preferred for flanged/horn models) or **heavy-duty 5/7-layer carton** for small versions.
- **Case thickness**: 9–12 mm plywood.
- **Pallet**: Heat-treated ISPM 15 with IPPC stamp (mandatory for wood).
- **Packing density**: 4–12 units per case typical; leave ≤5 cm void filled with foam/air bags.
- **Steel strapping**: PP strap minimum for carton, steel strap for wooden cases.
- **Moisture barrier**: Aluminum foil + desiccant for long sea voyages (>15 days).

---

## 3. Environmental Protection Requirements

| Hazard | Solution |
|---|---|
| Humidity / condensation | Desiccant + VCI film + foil barrier bag |
| Salt air (sea freight) | VCI + sealed PE bag |
| Temperature extremes | Foam insulation if >40°C swing |
| Static | ESD bag, grounded handling |
| Impact | EPE/EVA foam, drop-tested carton |
| Corrosion of flange | Coated / oiled flange face + cover |
| Rain during loading | PE wrap on pallet, "KEEP DRY" marking |

## 4. Marking & Labeling (Export Standard)

**On each unit / inner carton:**
- Product model, serial number, tag number
- Calibration date, firmware version
- Firmware/config backup reference

**On outer carton/case (shipping marks):**
- Consignee, PO number, item number
- Case number (e.g., **1/5, 2/5**)
- Gross / net weight (kg), dimensions (L×W×H cm)
- Country of origin
- Handling pictograms per **ISO 780**:
  - ⚠ Fragile
  - ☂ Keep dry
  - ↑↑ This way up
  - 🌡 Temperature limit (if applicable)
  - ⚡ ESD-sensitive (optional)
- Barcode / QR with packing list link

## 5. Shipping Documents

- Commercial Invoice
- Packing List (per case with weights & dimensions)
- Bill of Lading / Air Waybill
- Certificate of Origin (Form A / FTA if applicable)
- **Fumigation / ISPM 15 certificate** (for wooden packaging)
- Insurance certificate (recommended: All Risks, 110% CIF)
- **UN 38.3 test report** if lithium battery included
- MSDS if any special materials (rare for this product)
- Declaration of Conformity (CE/ATEX/IECEx certificates as applicable)
- Calibration certificate

---

## 6. Transport Mode Requirements

### Sea Freight (most common)
- Container: 20'/40' GP or LCL
- Secure pallets to container floor with lashing/airbags
- Desiccant: 1–2 kg per pallet for long voyages
- Avoid top-loading; mark "DO NOT STACK" if fragile

### Air Freight
- ISTA 2A minimum
- Note pressure changes: sealed bags may inflate — use breather valve or perforated bag
- Lithium batteries: IATA DGR Class 9, Section II if small

### Courier (DHL/FedEx/UPS)
- Double-box for single units
- ESD bag mandatory
- Declared value & HS code on invoice

---

## 7. Special Cases

**ATEX / IECEx certified units**
- Include certificate copy inside case
- Label outer box "Ex equipment — handle with care"

**Hygienic / sanitary (3-A, EHEDG)**
- Cleanroom-wrap, food-grade film
- Protect Tri-Clamp / dairy fittings with caps

**High-temperature / high-pressure models**
- Note on case: "Do not expose to >X °C"
- Keep flange gasket materials separate if elastomer-sensitive

---

## 8. Recommended Packing Flow (Summary)

```
Unit → ESD bag + desiccant
     → Foam-capped antenna + flange cover
     → EPE/EVA molded insert
     → Inner carton (5-layer) + product label
     → Master carton / plywood case
     → VCI film + desiccant
     → Pallet (ISPM 15) + strapping
     → ISO 780 marks + shipping docs
     → Container secured / air / courier
```
