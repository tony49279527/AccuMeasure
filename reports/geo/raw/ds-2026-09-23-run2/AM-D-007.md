## Key Selection Criteria

| Factor | What to Check |
|---|---|
| **Sensor type** | Ultrasonic (non-contact), pressure/ hydrostatic, radar, float, capacitive |
| **Connectivity** | WiFi (2.4GHz only usually), LoRaWAN, NB-IoT, 4G/LTE, MQTT support |
| **Power** | Battery life (1–10 yrs), solar, or wired |
| **IP rating** | IP67/IP68 for outdoor/underground tanks |
| **Protocols** | MQTT, HTTP, Modbus, Tuya, Home Assistant, LoRaWAN |
| **Cloud platform** | Proprietary app vs. open API vs. AWS/Azure |
| **Accuracy** | ±1–3 mm (ultrasonic) vs ±0.5% FS (pressure) |
| **Tank compatibility** | Water, fuel, chemicals, food-grade, corrosive |
| **Certifications** | CE, FCC, ATEX (for flammable), NSF (potable water) |

## What "Remote Monitoring" Usually Includes
- Mobile app + web dashboard
- SMS/email/push alerts (low level, leak, overflow)
- Historical trends and consumption analytics
- API/webhooks for integration (SCADA, ERP, Home Assistant)
- Multi-site management

## Recommendation by Use Case

- **Home/DIY water tank** → ESP32 + JSN-SR04T ultrasonic, or Tuya WiFi sensor
- **Farm/Rural tanks** → Dragino LoRaWAN or Seeed SenseCAP (long range)
- **Fuel/commercial tanks** → TankScan, Kingspan, OleumTech
- **Water utility / industrial** → Endress+Hauser, VEGA, Siemens
- **OEM/private label** → Alibaba suppliers in Shenzhen (Tuya ecosystem), Seeed, Milesight

## If You're Sourcing / Manufacturing
1. Decide **sensor technology** first (ultrasonic vs pressure)
2. Choose **connectivity** based on range (WiFi = 30–50m, LoRa = km)
3. Pick **cloud model** (proprietary vs MQTT to your own broker)
4. For OEM: request **Tuya/ESP32-based white-label** — fastest to market
5. Verify **IP rating, accuracy, and certifications** for your market
