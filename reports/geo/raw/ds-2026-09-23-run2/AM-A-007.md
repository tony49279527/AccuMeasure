# IoT Level Sensor for Remote Water Tank Monitoring

Here's a comprehensive guide to building an IoT water tank level monitoring system.

## System Architecture

```
[Tank Sensor] → [MCU + Comms] → [Cloud/Broker] → [Dashboard/App]
                                     ↓
                              [Alerts/SMS]
```

## Recommended Approaches

### 1. **Ultrasonic (Non-Contact)** — Most Popular
- **Sensor:** HC-SR04 (budget), JSN-SR04T (waterproof), or MaxBotix MB7040 (industrial)
- **Principle:** Measures distance from top of tank to water surface
- **Level** = Tank Height − Distance
- **Pros:** No contact with water, no corrosion
- **Cons:** Condensation/false echoes, needs clear line of sight

### 2. **Pressure Transducer (Submersible)**
- **Sensor:** 4–20 mA or 0–5 V submersible pressure sensor
- **Principle:** Hydrostatic pressure ∝ water depth
- **Pros:** Very accurate, works in sealed/dark tanks
- **Cons:** Must be submerged, cable entry sealing required

### 3. **Float / Reed Switch Array**
- **Pros:** Simple, cheap, reliable
- **Cons:** Only discrete levels (not continuous)

### 4. **Capacitive / Time-of-Flight (e.g., VL53L1X)**
- Good for small tanks, short range

## Wiring Example (ESP32 + JSN-SR04T)

```
JSN-SR04T  →  ESP32
VCC        →  5V
GND        →  GND
TRIG       →  GPIO 5
ECHO       →  GPIO 18 (via voltage divider to 3.3V!)
```

⚠️ **Important:** JSN-SR04T ECHO outputs 5V — use a voltage divider (1kΩ / 2kΩ) to protect ESP32.

## Firmware (ESP32 → MQTT)

```cpp
#include <WiFi.h>
#include <PubSubClient.h>

#define TRIG 5
#define ECHO 18
#define TANK_HEIGHT_CM 200.0   // sensor to bottom
#define SENSOR_OFFSET_CM 10.0  // sensor above max water

const char* ssid = "YOUR_WIFI";
const char* pass = "YOUR_PASS";
const char* mqtt_server = "broker.hivemq.com";

WiFiClient espClient;
PubSubClient client(espClient);

float readDistanceCM() {
  digitalWrite(TRIG, LOW); delayMicroseconds(2);
  digitalWrite(TRIG, HIGH); delayMicroseconds(10);
  digitalWrite(TRIG, LOW);
  long dur = pulseIn(ECHO, HIGH, 30000); // 30ms timeout
  return dur * 0.0343 / 2.0;
}

float readLevelPercent() {
  // Median of 5 readings to reject outliers
  float s[5];
  for (int i = 0; i < 5; i++) { s[i] = readDistanceCM(); delay(60); }
  for (int i = 0; i < 4; i++)
    for (int j = i+1; j < 5; j++)
      if (s[j] < s[i]) { float t=s[i]; s[i]=s[j]; s[j]=t; }
  float dist = s[2];

  float waterHeight = TANK_HEIGHT_CM - dist - SENSOR_OFFSET_CM;
  float pct = (waterHeight / TANK_HEIGHT_CM) * 100.0;
  return constrain(pct, 0, 100);
}

void connect() {
  while (!client.connected()) {
    if (client.connect("tank-sensor-01")) return;
    delay(2000);
  }
}

void setup() {
  Serial.begin(115200);
  pinMode(TRIG, OUTPUT); pinMode(ECHO, INPUT);
  WiFi.begin(ssid, pass);
  while (WiFi.status() != WL_CONNECTED) delay(500);
  client.setServer(mqtt_server, 1883);
}

void loop() {
  if (!client.connected()) connect();
  client.loop();

  float level = readLevelPercent();
  char payload[64];
  snprintf(payload, sizeof(payload), "{\"level\":%.1f}", level);
  client.publish("home/tank/level", payload);
  Serial.println(payload);

  delay(60000); // 1 min
}
```

## Power Considerations for Remote Sites

- **Wi-Fi:** ~1–2 W → needs mains or large solar
- **LoRa (< 1 km–15 km):** ~100 mW during TX → solar + 18650 lasts months
- **NB-IoT / LTE-M:** Low power + wide area, but SIM costs
- **Deep sleep ESP32:** ~10 µA → wake every 15 min, publish, sleep

**Solar sizing example (LoRa node):**
- Duty cycle: 10 s active @ 50 mA, 890 s sleep @ 50 µA
- Avg = (10·50 + 890·0.05)/900 ≈ 0.6 mA @ 3.7 V ≈ 2.2 mW
- A 1 W solar panel + 2000 mAh Li-ion = indefinite operation

## Best Practices

1. **Filter readings** — median-of-5 or Kalman filter to reject ultrasonic noise
2. **Temperature compensation** — speed of sound varies ~0.6 m/s per °C
3. **Fail-safe** — if `pulseIn` times out, don't publish bogus 0%
4. **OTA updates** — critical for remote installs (ArduinoOTA / ESPHome)
5. **Local fallback** — trigger pump cutoff locally even if cloud is down
6. **Antenna placement** — keep LoRa/Wi-Fi antenna out of metal tanks
7. **Watchdog timer** — auto-reboot on freeze
8. **Secure MQTT** — TLS + auth in production

## Typical Calibration

```
max_distance (tank empty) = Tank height - offset
min_distance (tank full)  = offset (water touching near top)

level% = (max_distance - measured) / (max_distance - min_distance) × 100
```
